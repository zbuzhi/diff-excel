这次更新主要让“找到变化、看清变化”更顺手。

### 先看结果，再按需导出

开始对比后直接查看差异，不再自动生成 Excel。确认后再导出带高亮的报告和完整日志；调整颜色、批注或输出目录时，不用重新比较。命令行 `--headless` 仍一次生成两个报告文件。

### 差异多了，也能全部找到

搜索和工作表、类型筛选覆盖全部差异，取消原来前 5,000 条的搜索限制。列表按每页 200 条加载，后台查询不会阻塞窗口，过期搜索结果也不会覆盖新输入。

点击一行，在右侧查看完整内容。新增或删除的文字范围会着色，类型、公式与计算结果的变化会单独说明。可以复制内容、连续查看上一条／下一条，也可以拖动表头调整旧、新内容列宽。

### 少做几次重复操作

- 支持向旧／新卡片定向拖入文件，一键交换版本。
- 记住最近文件、输出目录、高亮色、格式及批注选项，最近记录可以清空。
- 自动配对和低频导出选项按需展开；保留奶油色与圆形开始按钮，减轻边框、统一选中颜色。
- 返回文件设置后再进入结果页，会保留搜索、筛选和位置；输入改变时明确提示旧结果。
- 修复替换文件读取失败后仍可能使用旧工作簿的问题。
- 读取、比较和导出可以请求取消。解析／保存阶段会在当前操作结束后清理，避免留下未完成报告。

### 下载

- Windows x64：`DiffExcel-windows-x64.zip`，包含桌面程序 `DiffExcel.exe` 和终端程序 `diff-excel-cli.exe`。
- M 系列 Mac：`DiffExcel-macos-apple-silicon.dmg`。
- Intel Mac：`DiffExcel-macos-intel.dmg`。

Mac 打开 DMG 后拖入 Applications。本版本没有 Apple Developer ID 签名、公证或 Windows 代码签名，首次运行可能需要在系统设置中允许打开。`SHA256SUMS.txt` 提供三个下载包的校验值。

本机回归测试共 19 项通过；1 万行 × 20 列、9,999 处变化的样本已独立核对全部单元格内容、类型、公式、高亮、批注和日志，输入文件不变。Windows 与 Intel Mac 尚未做本轮真机复测。

仍支持 `.xlsx`，按坐标比较，不识别移动行或按业务主键对齐，也不重新计算公式。复杂图表、透视表和外部链接仍建议先用副本验证输出。
