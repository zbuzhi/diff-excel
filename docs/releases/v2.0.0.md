Diff Excel 2.0 用 Rust 重新开发了对比工具，并重新设计了桌面界面。

这次更新主要做了这些事：

- 支持全部工作表对比，自动匹配同名工作表，也可以手动配对不同名称的工作表。
- 在窗口中直接查看新增、删除和修改，支持筛选、搜索和完整内容详情。
- 底部圆形按钮开始对比，显示处理进度，完成后进入结果页；设置和结果可以来回切换。
- 导出带高亮的 Excel 和完整差异日志，可保留新文件格式、通过批注查看旧内容，并自定义高亮色。
- 支持拖入文件、Git difftool 参数启动和独立命令行模式。
- 修复带 XML 命名空间前缀的 XLSX 无法读取的问题，已用原始 1 万行 × 20 列样本复测。
- Windows 桌面版改用 DirectX/Vulkan，macOS 使用 Metal。

### 下载与安装

- Windows x64：下载 `DiffExcel-windows-x64.zip`，解压运行 `DiffExcel.exe`。终端使用 `diff-excel-cli.exe`。
- M 系列 Mac：下载 `DiffExcel-macos-apple-silicon.dmg`。
- Intel Mac：下载 `DiffExcel-macos-intel.dmg`。

Mac 打开 DMG 后，将应用拖入 Applications。本版本没有 Apple Developer ID 签名、公证或 Windows 代码签名，首次运行可能需要在系统设置中允许打开。

界面和使用说明见[项目首页](https://github.com/zbuzhi/diff-excel#readme)。`SHA256SUMS.txt` 包含三个下载包的 SHA-256 校验值。

### 对比范围

支持 `.xlsx`，按坐标比较值、类型和公式，不做移动行识别，也不重新计算公式。界面预览和搜索限前 5,000 条；导出的 Excel 和日志包含全部差异。原文件不会被修改。

Windows 原报错设备和 Intel Mac 真机仍需要更多使用反馈；跨平台构建检查不代表所有硬件环境都已验证。复杂图表、透视表和外部链接建议先用副本确认输出效果。
